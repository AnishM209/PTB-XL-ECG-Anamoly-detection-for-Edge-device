# Documentation

`ecg_dsp_pipelines.html` is the written summary of the DSP work: the system, why a notch is needed, both
pipelines with block diagrams and an explanation of every block, all tests in the order they were run with
their numbers, the conclusions, limitations and a map of the scripts. Open it in any browser; it is a single
self-contained file (fonts load from Google Fonts when online, with fallbacks offline).
